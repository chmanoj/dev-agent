# Product Overview

dev-agent is an AI-powered development workflow assistant that implements a structured four-phase development process for Python projects.

## Core Purpose
- Analyze existing large codebases through comprehensive local indexing
- Generate specifications, designs, and implementation plans
- Provide context-aware code generation consistent with existing patterns
- Maintain persistent state across development sessions

## Four-Phase Workflow
1. **Indexing Phase**: Analyzes codebase using Tree-sitter and vector embeddings
2. **Specification Phase**: Generates or refines project requirements
3. **Design Phase**: Creates technical design documents
4. **Implementation Phase**: Generates Python code and tests

## Key Features
- Interactive CLI with chat-based interface
- High-performance codebase indexing and analysis
- Session management with persistent state
- User approval workflows between phases
- Python-first with plans for multi-language support

## Target Users
Developers working with large Python codebases who need AI assistance for understanding, documenting, and extending existing projects.
