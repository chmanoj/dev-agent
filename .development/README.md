# Development Documentation

This directory contains development-related documentation, migration summaries, and implementation reports that track the evolution of the dev-agent project.

## Structure

- `migration-summaries/` - Documentation of major feature implementations and migrations
- `architecture-decisions/` - Architectural decision records (ADRs)
- `performance-reports/` - Performance analysis and optimization reports

## Purpose

These documents serve as:
- Historical record of development decisions
- Implementation guidance for similar features
- Troubleshooting reference for complex integrations
- Knowledge transfer for team members

## Maintenance

- Keep summaries updated when making significant changes
- Archive outdated reports when features are deprecated
- Reference these documents in code comments when relevant
